## `modern/`

Original to this project, added 2026-09-14. Flat geometric-primitive
silhouettes (circles/rects/polygons, no curves traced or adapted from any
existing piece set), generated for Chegga Web specifically to add piece
variety without a third-party licensing question. No external source,
no attribution required. Licensed the same as the rest of Chegga Web.

The rest of Chegga Web is a separate work; the third-party image files
above are aggregated with it, not derived from it.
